# Prototypes

Throwaway scripts from the 2026-10-08 feasibility research. They are evidence behind the numbers in `../plan.md` and
starting points for the tasks in `../tasks.md`. They are not the product: `src/zh.py` replaces them.

| Path | What it proves | Feeds task |
|---|---|---|
| brave-strings/pak.py | Stdlib Chromium pak v5 reader (with aliases), en/zh alignment, normalisation, tiering. Self-check: `python3 pak.py` | T-07, T-10 |
| brave-strings/tier1_sample.tsv, tier1_zh.txt | Output: first 50 tier-1 pairs; all 246 tier-1 zh phrases | T-07, T-10 |
| anki-build/media_map.py | Stdlib parser for the reference deck's zstd+protobuf media map: `zstd -dc media > media.pb; python3 media_map.py media.pb out.json` | T-09 |
| anki-build/media_map.json | Output: media index -> mp3 name for the reference deck | T-09 |
| anki-build/build.py | genanki deck with fixed ids, guid_for, due ordering, reused mp3s. Expects an extracted reference deck at `../apkg/col.db` (unzip the .apkg there and `zstd -dc collection.anki21b > col.db`) | T-13 |
| anki-build/import_test.py, reimport_test.py | Import/re-import into a scratch collection with `uv run --with anki`: no duplicates, scheduling kept | T-13 |
| anki-build/mk_model.py | Created the Yomitan Hanzi note type through AnkiConnect (Anki must be running; safe to re-run, it skips if the type exists) | T-18 |
| anki-build/csv_test.py | Alternative path (Anki TSV import) that was rejected because it cannot carry media | none (rejected) |
| data-sources/coverage.py | Overlap of SUBTLEX/wordfreq/HSK lists with the reference deck. Args: download dir, col.db. Needs the downloads in plan.md | T-11 |
| data-sources/wordfreq_zh_top1000.txt | Output: the candidate word list (wordfreq, the chosen source) | T-11 |
| data-sources/top1000_missing_from_deck.txt | Output: SUBTLEX top-1000 words missing from the reference deck (not the wordfreq list; recompute for wordfreq in T-16) | T-16 |
| learning-design/cov.py, deck.py | Token coverage curve of wordfreq top-N; HSK levels of the top 1000 in the reference deck | none (evidence for plan.md Contexto) |

Not copied, on purpose: downloaded datasets (re-fetch them in T-08; SUBTLEX-CH has no license), test collections and
.apkg outputs (regenerated by the scripts).
